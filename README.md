# CLAR: Cross-Modal Localization Assisted Restoration Method for Visible-Infrared Images

Official repository for the paper **"Cross-Modal Localization Assisted Restoration Method for Visible-Infrared Images"**.

## 📖 Overview
In complex scenarios, visible and infrared images suffer from modality-specific degradations. **CLAR** introduces an **Adaptive Cross-Modal Feature Aggregation (ACMFA)** module and a **dual-modal joint fine-tuning strategy** to preserve target-region features and boost both multi-degradation image restoration and downstream object detection.
